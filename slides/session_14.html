The foundation
What is Accessibility?
Designing so that every person — regardless of ability — can use your product.
Visual
Low vision, colour blindness, blindness
Need high contrast, alt text, screen reader support
Motor
Limited hand movement or dexterity
Need large tap targets, keyboard navigation
Cognitive
Dyslexia, ADHD, memory challenges
Need clear language, consistent patterns, no clutter
Hearing
Deaf or hard of hearing
Need captions, transcripts, visual alerts
The rulebook
WCAG Guidelines
Web Content Accessibility Guidelines — the global standard for accessible design.
A
Minimum
Basic must-haves
AA
Standard
Most apps aim here
AAA
Enhanced
Best possible experience
Real-world equivalent

Think of it like building codes. Level A = no open ditches in the floor. Level AA = ramps at entrances. Level AAA = braille on every sign.

Most common issue
Contrast & Colour
Low contrast text is the #1 accessibility failure — easy to fix, easy to test.
AA Standard
4.5:1 contrast ratio
Required for normal text. Use tools like Colour Contrast Checker or Figma plugins to verify.
Large Text
3:1 contrast ratio
Applies to text 18px+ (bold) or 24px+ (regular). Easier threshold but still critical.
Don't rely on colour alone
Colour blindness affects 1 in 12 men
Always pair colour with an icon, label, or shape. "Red = error" doesn't work if someone can't see red.
Beyond disability
Inclusive Design Principles
Accessibility helps disabled users. Inclusive design helps everyone.
Flexible Use
Support different ways of interacting — tap, type, voice, click.
Forgiving Design
Undo, confirm before delete, clear error messages. Everyone makes mistakes.
Plain Language
Short sentences, simple words. Not dumbing down — smarting up.
Clear Hierarchy
Headings, labels, and structure help screen readers and skimmers alike.
Curb Cut Effect
Kerb cuts (ramps) were built for wheelchairs — but cyclists, parents with prams, and delivery riders use them daily. Accessible design helps far more people than you think.
Remember this
Key Takeaway

"Accessible design isn't a feature you add at the end — it's a quality standard you build in from day one."

Check contrast on every text element — use a free tool
Never use colour as the only signal for state or meaning
Test with keyboard-only navigation — no mouse

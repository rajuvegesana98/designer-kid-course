Why it matters
People Judge Text Before They Read It
Within seconds, typography sets the tone: serious or playful, cheap or premium, easy or hard.
Feels premium
Clean sans-serif, tight spacing, generous whitespace
Think Apple, Notion, Linear. Simple but intentional.
Feels cheap
Comic Sans on a bank app, tiny font on a form
Even great content gets dismissed if the type feels wrong.
Real-world analogy

Typography is like the tone of voice in a speech. Same words, different delivery — completely different impression.

Font families
Four Families You Need to Know
Serif
Elegant & Trustworthy
Has small "feet" at ends of letters. Feels traditional, editorial, luxury. Use for headlines on premium brands.
Sans-Serif
Clean & Modern
No feet. Clear, minimal, digital-native. Best for UI body text and most apps.
Monospace
Technical & Precise
Each character is same width. Feels technical, code-like. Use for code blocks, data, terminal UIs.
Display
Bold & Expressive
Designed for large sizes only. Creates personality. Use only for big headlines, never body text.
Type scale
Build a Type System Once
A type scale is a set of pre-defined sizes. Pick from it — never random sizes.
H1 H2 H3 Body Small Caption
Heading
Big, bold, display font
Sets page intent. One per section.
Body
16–18px, regular weight
Everything people actually read. Keep readable.
Caption
11–13px, medium weight
Labels, hints, timestamps. Use sparingly.
Readability
Three Rules That Save Your Users' Eyes
Line Length
45–75 characters per line
Too wide = eye loses its place. Too narrow = too many jumps. About 600px is ideal for body text.
Line Height
1.4–1.7× the font size
Breathing room between lines. Cramped text feels overwhelming. 16px font → 24–27px line height.
Contrast
4.5:1 minimum ratio
Light grey on white = invisible to many users. Use a contrast checker tool. Accessibility requires this.
Quick test

Squint at your screen. Can you still read it? If not, the contrast or size is too low.

Font pairing
Two Fonts Are Enough
More fonts = more confusion. Pick one display for headings, one sans-serif for body.
Works great
Syne + DM Sans
Bold expressive heading + clean readable body. High contrast pairing — the personality shows in the headline, not the body text.
Works great
Playfair Display + Lato
Elegant editorial heading + neutral body. Great for lifestyle, magazine, luxury brands.
Avoid
Two display fonts together
They compete. The page feels noisy and unprofessional. Same family is fine — different weights.
Pro tip
Google Fonts pairs well
Free, fast-loading, and paired suggestions built-in. Start here before buying custom fonts.
What to avoid
Typography Mistakes to Stop Making
Mistake 1
Using 6+ font sizes randomly
Stick to your type scale. Random sizes break hierarchy and look amateur.
Mistake 2
All caps for long text
ALL CAPS is hard to read at length. Use for short labels and section headers only.
Mistake 3
Tiny body text (<14px)
Looks elegant but fails older users, mobile users, and accessibility audits.
Mistake 4
Low contrast text on busy backgrounds
Gradient backgrounds with white text. Looks cool in mockups, unreadable in real use.

Definition
What Is a Micro-interaction?
A micro-interaction is a single-purpose animation triggered by a user action. It lasts less than a second and tells the user something happened.
🔔
Trigger
What starts it — a tap, a swipe, a form submit, a page load.
⚙️
Rules
What happens — the object that moves, how far, how fast.
💬
Feedback
What the user sees — the visual or haptic response to their action.
🔁
Loops & modes
Does it repeat? Does it change after a long time? Does it end?
DESIGNER_KID
UX Value
Why Motion Matters
✅
Confirms action
A button that bounces on tap tells you the tap registered. Without it, you tap again — and submit twice.
🧭
Orients the user
A panel sliding in from the right tells you new content appeared. You know where you are spatially.
⏳
Manages wait time
A loading spinner or skeleton screen tells you to wait. Without it, users assume the app is broken.
🎉
Creates delight
Confetti on a goal completion, a satisfying toggle snap — these moments make users feel rewarded.
👁
Guides attention
Movement draws the eye. An animated badge or pulsing dot says "look here" without words.
🤝
Builds trust
Polished motion signals quality. A janky, abrupt transition makes the product feel unfinished.

Principles
The 4 Animation Levers

Duration

100–300ms for micro-interactions. Over 500ms feels sluggish. Under 100ms is invisible. Sweet spot: 200ms.

Easing

ease-out = fast start, slow end (things coming to rest). ease-in = slow start, fast end (things leaving). ease-in-out = smooth both ends.

Delay

Stagger list items 30–50ms apart to create a sequence that feels orchestrated, not chaotic. Never delay the first element — the user is waiting.

Property

Prefer animating opacity and transform (translate, scale, rotate) — they run on the GPU and never cause layout reflow. Avoid animating width, height, or top/left.

DESIGNER_KID
Patterns
Common Micro-interaction Patterns
🔘
Toggle
Thumb slides, background changes colour. Duration: 200ms ease-out. Shows ON/OFF state instantly.
⭕
Loading spinner
Infinite rotation on a ring or dots. Signals "wait". Stops and transitions to content when done.
✏️
Input focus
Border colour changes, label floats up. Tells the user exactly which field is active.
✅
Success state
Checkmark draws in, button turns green, brief scale-up. Makes form submits feel satisfying.
🚨
Error shake
Horizontal shake (4px left-right, 2 cycles). Universal signal for "wrong". Don't use red alone — motion helps colourblind users too.
👆
Hover lift
Card translates up 2–4px, shadow deepens. Signals "this is clickable". Duration: 150ms ease-out.

Figma
Prototyping Motion in Figma
01

Smart Animate

Same layer name in two frames → Figma interpolates position, size, opacity. No keyframes needed.

02

Triggers

On Click, On Hover, After Delay, Mouse Enter/Leave — pick what starts the animation.

03

Easing presets

Ease In, Ease Out, Ease In and Out, Spring — use Spring for bouncy toggles and confirmations.

04

Component variants

Button/Default + Button/Hover + Button/Pressed — wire them up with "While Hovering" and "On Click" triggers.

05

Preview on phone

Use the Figma Mirror app — motion prototypes feel totally different on a real device vs desktop.

Hands-On
Activity — Animate a Component
Your Task (20 min)
  1. In Figma, create a button component with 3 variants: Default, Hover, Pressed.
  2. Wire Default → Hover with "While Hovering" trigger, Smart Animate, 150ms ease-out.
  3. Wire Default → Pressed with "On Click" trigger, Spring easing.
  4. Bonus: Add a loading state — spinner appears for 1.5s after press, then shows a checkmark.
